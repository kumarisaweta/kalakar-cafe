# Cafe Kalakar Design System

## Brand Identity
- Name: Cafe Kalakar
- Vibe: Artistic, Warm, Modern Indian Cafe
- Feel: Premium but approachable

## Color Tokens
- Primary: #C8502A (warm terracotta/coffee)
- Secondary: #F5E6D3 (cream/latte)
- Accent: #2C1810 (dark espresso)
- Neutral: #FAF7F4 (off white background)
- Text: #1A1108 (deep brown)

## Typography
- Heading Font: Playfair Display (serif, elegant)
- Body Font: Inter (clean, readable)
- Scale: 12/14/16/20/24/32/48/64px

## Spacing System
- Base grid: 8px
- Sections: 80px-120px padding
- Cards: 24px padding
- Gaps: 16px/24px/32px/48px

## Animation Rules
- Use Framer Motion for ALL animations
- Scroll-triggered fades on every section
- Staggered reveals on menu cards
- Smooth hover on buttons (scale 1.02)
- Page transitions: fade + slight Y movement
- 3D elements: subtle float animation

## Component Patterns
- Buttons: rounded-full, warm colors, hover scale
- Cards: soft shadow, rounded-2xl, cream background
- Nav: transparent → solid on scroll
- Hero: Full screen, 3D element prominent

## Avoid
- Generic blue/grey color schemes
- Sharp corners everywhere
- Static non-animated sections
- Comic Sans or random fonts
- Cluttered layouts
